# UI evidence (synthetic data)

Generated by `tools/ui-qa` against the app served by `scripts/policyguard_serve.sh` on http://127.0.0.1:8780 (uvicorn without reload, the same process used in production builds of this app; there is no front-end build step).

| File | Produced by | Conditions |
|---|---|---|
| `audit-summary.json` | `npm run audit` | Google Chrome via Playwright 1.64.1; widths 320, 375, 768, 1024, 1440 px; axe-core 4.13.0 with tags wcag2a, wcag2aa, wcag21a, wcag21aa, wcag22aa (at 375 and 1440 px); keyboard-only run at 1280×900 |
| `screens/<page>-<width>.png` | `npm run audit` | Full-page screenshots, device scale factor 1, light colour scheme |
| `axe/<page>-<width>.json` | `npm run audit` | Violations, incomplete checks and pass counts |
| `lighthouse/<page>-<preset>.report.{html,json}`, `lighthouse/summary.json` | `npm run lighthouse` | Lighthouse 13.5.0 lab runs, mobile (default throttling) and desktop presets, headless Chrome on an Apple M2 laptop; the demo session cookie is removed from saved reports. `summary.json` records the fetch time, user agent, throttling method and form factor of each run |

Lab results are not field data: no real-user LCP/INP/CLS was collected. App pages are deliberately `noindex`, which lowers their Lighthouse SEO score; the public landing page `/` is the page meant for indexing.
